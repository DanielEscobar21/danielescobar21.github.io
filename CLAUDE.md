# CLAUDE.md - Daniel Escobar Portfolio

## Project Overview

Personal portfolio website for Daniel Escobar (descoba.dev), deployed on GitHub Pages as a static site.

## Tech Stack

- **Framework:** Next.js 15 with static export (`output: 'export'`)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 3
- **Animations:** Framer Motion
- **Icons:** FontAwesome (brands)
- **Package Manager:** Yarn 3
- **Deployment:** GitHub Pages (static export to `out/`)
- **Domain:** descoba.dev

## Project Structure

```
src/
  app/           # Next.js App Router (layout.tsx, page.tsx, globals.css)
  content/       # Static content and translations (texts.ts)
  context/       # React contexts (ThemeContext.tsx)
components/      # Shared components (Navbar.tsx, etc.)
public/          # Static assets (images, resume, favicon)
out/             # Build output (static HTML, do not edit)
```

## Commands

```bash
yarn dev        # Start dev server (localhost:3000)
yarn build      # Build static export to out/
yarn lint       # Run ESLint
yarn export     # Alias for build (next build)
```

## Key Conventions

- **Bilingual:** All UI text lives in `src/content/texts.ts` with `es` and `en` keys. Always update both languages when modifying content.
- **Theme:** Dark/light mode via `ThemeContext`. Uses Tailwind's `dark:` variant with CSS custom properties (`light-base`, `dark-base`, `primary-*`).
- **Static export:** No server-side features (no API routes, no SSR). Images are unoptimized (`images.unoptimized: true`).
- **Path alias:** `@/*` maps to `./src/*` in tsconfig.
- **Single page:** The portfolio is a single-page app with sections (hero, about, projects, experience, education, contact).

## Deployment

The site builds to `out/` and is served via GitHub Pages with custom domain `descoba.dev`. The `CNAME` file at root must not be deleted.

## Do's and Don'ts

- **Do** run `yarn build` after changes to verify static export works.
- **Do** keep both `es` and `en` translations in sync.
- **Don't** add API routes or server-side features (static export only).
- **Don't** delete the `CNAME` file.
- **Don't** modify files in `out/` directly — they are generated by the build.
